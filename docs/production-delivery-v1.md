# v1.0.0 生产交付记录

交付日期：2026-11-08。源码与公开附件见 [v1.0.0 Release](https://github.com/ScyPolit/AwardCollection/releases/tag/v1.0.0)。

## 功能与工程整理

- 移除编辑器顶部导入格式说明，画布随可用空间伸展，工具栏换行不遮挡编辑区域。
- 共享模板先复制再修改；个人副本默认私有，作者可决定共享。部门管理员调离原部门后不能再编辑其部门模板。保存、预览、下载及批次选择统一由服务端校验。
- 根目录临时文件集中到 `testTemp/history/`，开发数据集中到 `testTemp/development/`，私有素材集中到 `resources/private/`。正式测试保留在后端测试模块内。
- 新增可校验、可迁移的私有初始化包，以及可公开分发的三款通用模板包；两类包分开保存。
- 修复 Web 暂停时备份遗漏 TLS 的问题；TLS 缺失、归档不完整或摘要错误均拒绝标记完成。

## 已执行的数据范围

按系统所有者明确确认，先完整备份，再清理测试业务。清理前有 2 个非超管账号、1 项竞赛、4 个批次、901 份证书；已清理其相关名单、任务、通知、会签、查验记录及当前媒体中的业务产物。完整历史保存在独立备份中。

保留原超管、1 个「标准模板」的最新画布、2 款导入字体、7 款内置字体、2 个部门、1 枚公章及其图片版本、系统配置和编号计数器。模板最新版本 id=21 的画布、字体、公章和超管密码与初始化前一致。计数器保留，避免后续正式证书重用旧测试编号。

旧登录会话已撤销，使用原超管账号重新登录。原数据库容器和命名卷保留，未操作其他应用。初始化不会在启动、更新或安装 Release 时自动发生；今后的正式业务不属于本次清理授权。
