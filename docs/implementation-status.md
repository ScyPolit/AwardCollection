## 功能实现和证据

- 多角色、多部门、负责人协作、竞赛立即生效、统一 Excel 与自由奖项：已有实现和自动化测试，本轮通过负责人和两个管理员实际走通新批次。
- 整批版本、全部部门审批、本人成员回避、旧版本拒绝、自动任务：已有测试；本轮观察到 1/2 审批时无任务、无证书，2/2 后自动生成并统一发布。
- 模板库、复制、背景、字段图层、位置尺寸、字号颜色对齐、拖放、编号正文和水印、公章位与每批资源选择：已接入实际渲染，并以不同背景和双部门测试印章验证。模板字体使用部署的统一中文字体。
- 部门多枚公章和版本：部门管理员各自上传，负责人只读元数据选章，写入权限和原图隔离有测试。
- 账号管理、已有账号授权、新建部门、公开字段设置、动态工作台、应急签发/作废和主要通知：已有界面及 API；对应权限和密码复核有自动化测试。本轮额外通过已有账号关联界面。
- 证书编号查验：管理员免验证码和访客验证码均在目标浏览器成功，脱敏显示有截图；验证码复用与无关账号下载拒绝有测试。
- 作废部分审批维持有效、全体批准作废、超管应急：自动化测试通过；本轮未再修改历史测试证书状态。
- PDF 真实增量签名与 PNG：实际签名验证通过。数字签名字段不可见，画面仅显示模板中的部门印章。图片附件使用 .png，批次详情提供 ZIP，压缩超过 8 MB 转用临时磁盘。
- 持久化、每日备份、临时清理及日志轮换：已部署。正式证书和关键记录不在清理范围；早先隔离备份恢复演练仍保留历史记录。
