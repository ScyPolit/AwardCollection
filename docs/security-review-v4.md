# 本版安全验证范围

以 [OWASP ASVS 5.0](https://owasp.org/www-project-application-security-verification-standard/) 为核对参考。ASVS 的 L3 是高保障验证目标，不能用安装某个组件来获得，也不能将本次开发回归描述为 L3 认证、等保三级认证或“绝对安全”。本版没有独立第三方渗透测试或合规认证。

已实现的主要控制：

- 服务端按账号、部门、业务对象验证权限；角色变更独立接口；按2026-11-08需求，部门管理员和超管可审批本人提交或修改的批次，普通负责人仍无用印批准权。
- 业务删除保留历史原件与审计；账号删除同时停用；日志无修改和删除接口。签名证书内容通过更正批次重新审批。
- 会签提交时以独立用途的 HMAC 冻结名单、模板快照与输出配置；部门公章可待选，由授权管理员确认，确认前先校验原冻结内容，服务器只更新本部门用章并重算摘要；审批和 worker 再验证。公章与字体文件校验摘要，下载 PDF / PNG / ZIP 检查已保存摘要，发现不一致阻止使用。
- 富文本清洗、严格媒体资源限制、XML 实体与原型属性拒绝、Office ZIP 解压/页数/元素/大小上限。渲染浏览器仅访问本地编辑器静态资源和映射字体；不持有用户登录凭据。
- 旧 Office 转换使用独立非 root 容器，根文件系统只读、临时盘限额、内存与进程限制、55 秒超时；子进程通过叠加 seccomp 拒绝 connect，阻止转换期间向外联网。
- HTTPS TLS 1.2/1.3、自签服务器证书、Secure / HttpOnly / SameSite 会话 cookie、CSRF 验证、八小时会话、代理覆盖来源 IP、生产随机密钥检查。原 HTTP 入口跳转到 HTTPS。
- API 和 worker 以非 root 身份运行；Docker 不暴露 PostgreSQL / 转换器；不挂载 Docker socket；日志轮换；部署前备份和发布回滚检查。
- 生产依赖升级并固定解析版本约束，分别扫描后端、主前端和 PPT 编辑器。零已知漏洞仅代表扫描时数据库和所列依赖范围，不能证明不存在未知漏洞。

自签 HTTPS 证书需在学校管理设备上安装信任，公有浏览器不会自动信任。可下载的 server.crt 只含公钥；私钥仅保存在 Docker TLS 卷中。PDF 部门自签身份同样需要学校分发信任根。PNG 不携带 PDF 数字签名，核验应以系统记录和签名 PDF 为准。

仍有实际边界：拥有主机、数据库和签名密钥全部控制权的攻击者可以绕过应用控制；同机备份不能抵抗整机存储损坏。主机及管理面板运维、异机备份、密钥离线托管和独立安全评估属于持续维护范围，不能由一次代码升级保证。
