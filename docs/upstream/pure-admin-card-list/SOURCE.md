# 模板商城页面来源

复用 Pure Admin 官方商品卡片列表页，固定版本 fae75ad1cd52d11a7279931ef5bba2b80e363c7b，采用原项目 MIT 许可。原始页面、卡片组件与许可证保存在同目录，便于核对。

- [官方 CardList 页面](https://github.com/pure-admin/vue-pure-admin/blob/fae75ad1cd52d11a7279931ef5bba2b80e363c7b/src/views/list/card/index.vue)
- [官方 ListCard 组件](https://github.com/pure-admin/vue-pure-admin/blob/fae75ad1cd52d11a7279931ef5bba2b80e363c7b/src/views/list/card/components/ListCard.vue)

应用保留原页面的搜索工具栏、响应式卡片列、卡片样式与分页结构，将产品数据替换为真实证书模板，补入实际模板缩略图、预览、选用及复制编辑功能。没有新设计一套商城视觉风格。
