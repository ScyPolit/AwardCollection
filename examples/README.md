# 演示模板

README 截图中的三款证书样式可直接导入系统，均为本项目原创，按 MIT 许可证提供。它们只使用内置字体及自包含 SVG 背景，无学校校徽、部门公章或真实获奖数据。

| 样式 | 下载 |
| --- | --- |
| 典雅蓝金 · 荣誉证书 | [classic-blue.json](templates/classic-blue.json) |
| 清新青绿 · 创新竞赛 | [evergreen.json](templates/evergreen.json) |
| 极简留白 · 获奖证书 | [minimal.json](templates/minimal.json) |

使用管理员账号新建模板，点击“导入模板”选择 JSON，然后核对字段、页面尺寸和字体。正式签发前，为竞赛的每个盖章部门增加对应公章位，再保存并发布模板。

演示文件含 `SAMPLE · 演示证书` 字样，无公章，也不是有效证书。导入不会自动创建竞赛、账号或签发记录；生产实例中保留的“标准模板”不会被自动替换。
