This fork adds the AwardCollection save/field/seal bridge and an isolated static rendering entry; uses the local authenticated font catalog, preserves whitespace and adds numeric first-line indentation. Paid cloud/AI services are not connected. The native local slide editing, native undo/redo, shortcuts, context menus, shapes, images, text, tables/charts, presentation and file import/export remain in the source editor.
Modified source is distributed at https://github.com/ScyPolit/AwardCollection/tree/main/frontend/ppt-editor .
