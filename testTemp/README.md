# 临时工作区

测试运行日志、截图、下载缓存、临时媒体、部署传输文件和待发布产物统一放在本目录。除本说明外，所有内容均被 Git 忽略，不进入源码包或 Docker 构建上下文。

- `history/`：从项目根目录归档的历史 `.tmp-*` 文件和目录，保留原文件内容。
- `production-release-20261108/`：生产交付的临时构建、回归和打包文件。

可复用的部署程序放在 `deploy/`；正式自动化测试保留在 `backend/awards/test_*.py`；可公开的示例放在 `examples/`。个人编辑器配置保留在原有目录。

本目录可能含账号会话、校章或授权字体，不得整体上传到公开仓库或 Release。确认不再需要且已有备份后再由维护人员清理。
